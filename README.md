## Sample Bug Report — Synthetic Example

**ID:** DEMO-QA-001

**Title:** Booking subtotal does not update after changing the number of nights.

**Steps:**
1. Open a demonstration booking form.
2. Set room price to INR 2,000 per night.
3. Change booking duration from 1 night to 2 nights.
4. Check the displayed subtotal.

**Expected:** Subtotal updates to INR 4,000 before taxes and fees.

**Simulated observed:** Subtotal remains INR 2,000 until the page is refreshed.

**Note:** This is a fictional example showing my bug-reporting approach, not a defect found in a real client system.
